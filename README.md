# WTS AutoFlood

Аддон для **World of Warcraft: Burning Crusade Classic (2.5.6)**, помогающий продавать услуги ремесла в чате.

## Возможности

- **Сохранённые заготовки объявлений** — переключение прямо из окна аддона, без правки текста заново
- **Shift+клик по рецепту** в книге профессий вставляет кликабельную ссылку в сообщение
- **Выбор чата или канала в окне** аддона, заходить в настройки не нужно
- **Назначение горячей клавиши** отправки не выходя из окна
- **Кнопка на миникарте**, перетаскиваемое окно, сохранение позиции
- **Автоотправка по таймеру** в гильдейские чаты, интервал 10–120 секунд
- **Русский и английский интерфейс**, кириллический шрифт вшит в аддон — работает на enUS-клиенте без квадратиков

## Ограничение

В публичные каналы (Trade, Say, Yell) игра запрещает отправку сообщений без действия игрока — это встроенная защита клиента от спама. Туда сообщение уходит по нажатию кнопки «Отправить» или назначенной клавиши.

Автоотправка по таймеру работает в чатах Гильдия, Офицерский, Группа, Рейд и Поле боя.

## Установка

Скопируйте папку `WTSAutoFlood` в `Interface\AddOns\` вашего клиента.

Команды: `/wts` или `/wtsautoflood`.

## Происхождение и лицензия

Это **изменённая версия** аддона **TradeAnnouncer** за авторством **Kalivos**.

Изменения внесены в июле 2026 года: перенос с retail 11.x на TBC Classic 2.5.6, снятие зависимости от аддона MessageQueue, русская локализация со встроенным шрифтом, сохранённые заготовки, вставка ссылок на рецепты по shift+клику, назначение горячей клавиши и выбор канала из главного окна.
